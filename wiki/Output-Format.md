# Output Format

出力される Excel ファイルの構成を説明します。

## ファイル名

```text
集計結果_[YYYYMMDD-YYYYMMDD]_YYMMDD-HHMMSS.xlsx
```

## 列構成

| 列 | 内容 |
|---|---|
| No | 担当講師N0 を表示 |
| 氏名 | 担当講師名 を表示 |
| 教室 | 教室名を表示 |
| 総授業数 | 全週分の授業数の合計 |
| 授業1, 授業2, ... | 各週の授業数 |
| 平均HW1, 平均HW2, ... | 各週の宿題平均ページ数 |
| Lap数1, Lap数2, ... | 各週の Lap 実施数 |
| Lap％1, Lap％2, ... | 各週の Lap 実施率 |
| テスト数1, テスト数2, ... | 各週の確認テスト実施数 |
| テスト％1, テスト％2, ... | 各週のテスト実施率 |

## 色のルール

- 総授業数: Lavender #E6E6FA
- 授業数: Khaki #F0E68C
- 宿題平均: 通常色
- Lap率・テスト率: 条件付き書式で強調

## 条件付き書式

- 宿題平均が 6 未満の場合はオレンジ
- テスト率が 70% 未満の場合は深紅
