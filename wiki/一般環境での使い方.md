# 一般環境での使い方
> [!NOTE]
> EXEファイルを実行するやり方です\
> Python環境は[こちら](Python環境での使い方)

## 必要なもの

- Windows 環境
- 実行ファイル(.exe)→ダウンロードは[こちら](https://github.com/sam-hat-86/MSL_Checker/raw/refs/heads/main/MSL集計ソフト.exe)
- 入力用の Excel ファイル

## 集計処理の実行

### 1. EXEファイルを実行する
もしかしたら、「セキュリティーが～」とか出てくるかもしれませんが、信じてください。

### 2. 入力ファイルを選ぶ

集計用データには、少なくとも次の列が必要です。
- 出欠
- 担当講師名
- 担当講師N0←O(オー)じゃなくて0(ゼロ)らしいです。なんで？
- 教室

### 3. 出力ファイルの作成

集計済みのファイルは集計元のファイルと同じ場所(Directory)に保存されます。
```
ファイル名："集計結果_[(集計期間)]_(集計処理日時).xlsx"
(集計期間)："yyyymmdd-yyyymmdd"形式
(集計処理日時)："yymmdd-hhmmss"形式
```
例えば集計期間が[2025/01/01~2025/02/28]で、処理日が[2025/01/01-12:34:56]なら、
```
ファイル名："集計結果_[20250101-20250228]_250101-123456.xlsx"
```
になります。
