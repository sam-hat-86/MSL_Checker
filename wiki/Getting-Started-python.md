# Python環境での使い方

このページでは、MSL Checker を初めて使うときの最短手順を説明します。

> [!CAUTION]
> Python環境で実行できる場合の手順です。
> 一般環境は[こちら]()を参照してください。

> [!TIP]
> 先に仮想環境(venvなど)を作成してから依存パッケージを入れると、環境差分を分離しやすくなります。

## 必要なもの

- Windows 環境
- Python 実行環境、または配布済みの実行ファイル
- 入力用の Excel ファイル

## セットアップ

### 1. 依存パッケージを入れる

```bash
pip install -r requirements.txt
```

### 2. スクリプトを起動する

```bash
python MSLdata_check.py
```

### 3. 入力ファイルを選ぶ

起動後に表示されるダイアログで、集計元の Excel ファイルを選択します。

## 入力ファイルの前提

少なくとも次の列が必要です。

- 出欠
- 担当講師名
- 担当講師N0
- 教室

## 結果の見方

出力ファイルは入力ファイルと同じ場所に保存されます。
ファイル名には集計期間が含まれます。
