# Usage

実際の運用でよく使う手順をまとめます。

## 基本操作

1. `MSLdata_check.py` を起動する
2. 集計元の Excel ファイルを選ぶ
3. 処理完了まで待つ
4. 出力された Excel を確認する

## 集計内容

- 講師別の授業数集計
- 総授業数の算出
- 宿題ページ数の平均化
- Lap 実施数と実施率の算出
- テスト実施数と実施率の算出

## 実務上の注意

- `出欠` が `出席` の行だけが集計対象になります
- `担当講師名` の全角英数字は自動で整形されます
- 日付列がある場合は、集計期間とシート名に反映されます

## 出力のポイント

- D列に総授業数が表示されます
- 総授業数は Lavender 色で強調されます
- 週別の「授業」列は Khaki 色で表示されます
