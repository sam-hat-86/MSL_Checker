# MSL Checker

Excelの出席・授業データを集計・分析し、講師別・週別の詳細レポートを自動生成するツールです。

## 機能

- **高速データ読み込み**: fastexcel エンジンによる高速化（フォールバック対応）
- **自動データクレンジング**: 全角英数字変換、列名の自動生成・重複排除
- **複数指標の計算**:
  - 授業数（出席人数）
  - 宿題平均ページ数
  - ラップテスト実施状況
  - 確認テスト実施状況
  - テスト実施率

- **週別レポート生成**: ピボット処理による講師別・週別の見やすいサマリー
- **自動ファイル出力**: 集計期間を含むファイル名で自動生成
- **高度なExcel装飾**:
  - 条件付き書式（宿題平均 < 6ページ：オレンジ、テスト率 < 70%：赤）
  - ペイン固定・オートフィルター設定
  - 日本語フォント対応（Noto Sans JP）
  - 高DPI対応


## 使用方法

### 入力ファイルの要件

以下の列が必須です:
- **出欠** - 「出席」「欠席」などの出席状況
- **担当講師名** - 講師名（全角英数字は自動変換）
- **担当講師N0** - 講師ID/番号
- **教室** - 教室情報

以下の列があると集計に活用されます（オプション）:
- **日付** または **授業日** - 集計期間の自動判定用
- **ラップテスト**系の列 - ラップテスト実施状況
- **確認**系の列 - 確認テスト実施状況
- **宿題名**系の列（3列1セット）:
  - 宿題名、宿題開始ページ、宿題終了ページ

## 出力ファイル

```
集計結果_[YYYYMMDD-YYYYMMDD]_YYMMDD-HHMMSS.xlsx
```

生成されたファイルは入力ファイルと同じディレクトリに出力されます。

### 出力シートの構成

| 列 | 説明 | 色 |
|-----|------|-----|
| No | 講師ID | （なし） |
| 氏名 | 講師名 | （なし） |
| 教室 | 教室 | （なし） |
| 総授業 | 授業数合計 | #E6E6FA（Lavender） |
| 授業| 各週の指導生徒数 | #F0E68C（Khaki） |
| 平均HW | 各週の宿題平均ページ数 | グレー/白 交互 |
| Lap回数 | 各週のラップテスト実施数 | グレー/白 交互 |
| Lap％ | 各週のラップ実施率 | グレー/白 交互 |
| テスト回数 | 各週の確認テスト実施数 | グレー/白 交互 |
| テスト％ | 各週のテスト実施率 | グレー/白 交互 |

### 条件付き書式

- **宿題平均 < 6ページ**: 背景色オレンジ
- **テスト実施率 < 70%**: 背景色深紅（白文字）

## 技術詳細

### データ処理フロー

1. **ファイル読み込み**
   - fastexcel→openpyxl へのフォールバック対応
   - 余分な列の自動ネーミング

2. **データクレンジング**
   - 出席データのフィルリング
   - 全角英数字 → 半角変換

3. **指標計算**
   - 宿題ページ数: 終了ページ - 開始ページ + 1
   - テスト実施有無の判定

4. **ピボット処理**
   - 講師・教室別、週別の集計

5. **Excel出力**
   - xlsxwriter による高速フォーマット
   - 日本語フォント対応
   - 高DPI対応

### パフォーマンス

- 10,000行程度のデータで数秒以内に完了

## トラブルシューティング

### エラー「必須の列が見つかりません」

入力ファイルに以下の列が存在することを確認してください:
- 出欠
- 担当講師名
- 担当講師N0
- 教室

### ファイルが開けない

- Excelファイルが破損していないか確認
- `.xlsx`, `.xls`, `.xlsm` 形式に対応しています

## Windows DPI対応

このツールは高DPI ディスプレイに自動対応します:
- GUI自動スケーリング
- フォント自動調整
- 日本語フォント（Noto Sans JP）使用で見やすさ向上
