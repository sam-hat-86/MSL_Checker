# Output Format
> [!IMPORTANT]
> この形式は出力ファイルの見た目と列構成をまとめたものです。実際の色分けは Excel 側の条件付き書式に依存します。

## ファイル名

```text
集計結果_[YYYYMMDD-YYYYMMDD]_YYMMDD-HHMMSS.xlsx
```

## 列構成

| 列 | 内容 |
|---|---|
| No | 担当講師N0 を表示 |
| 氏名 | 担当講師名 を表示 |
| 教室 | 教室名を表示 |
| 総授業数 | 全週分の授業数の合計 |
| 授業1, 授業2, ... | 各週の授業数 |
| 平均HW1, 平均HW2, ... | 各週の宿題平均ページ数 |
| Lap数1, Lap数2, ... | 各週の Lap 実施数 |
| Lap％1, Lap％2, ... | 各週の Lap 実施率 |
| テスト数1, テスト数2, ... | 各週の確認テスト実施数 |
| テスト％1, テスト％2, ... | 各週のテスト実施率 |

## 色設定

GitHub Wiki では色のプレビューは出ないため、設定値を文字で管理します。

| 項目 | 基本色 | 条件違反の色 | 違反条件 |
|---|---|---|---|
| 総授業数 |  | - | - |
| 授業数 | カーキ | - | - |
| 宿題平均 | 通常色 | オレンジ | 6未満 |
| Lap率・テスト率 | 通常色 | トマト | 70%未満 |
