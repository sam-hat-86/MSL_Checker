# Troubleshooting

よくある問題と対処方法を、一般環境(EXE) と Python環境(py) に分けてまとめます。

> [!WARNING]
> 表示崩れや集計失敗がある場合は、まず入力ファイルの列名と拡張子を確認してください。

## 目次

- [一般環境(EXE)](#一般環境exe)
- [Python環境(py)](#python環境py)

## 一般環境(EXE)

### エラー: 必須の列が見つかりません

次の列が入力ファイルに存在するか確認してください。

- 出欠
- 担当講師名
- 担当講師N0
- 教室

### ファイルを選んでも反応がない

- Excel ファイルが他のアプリで開かれていないか確認してください
- 入力ファイルの形式が `.xlsx`, `.xls`, `.xlsm` であることを確認してください

### 文字が崩れる

- Windows の表示倍率が極端に高い場合、フォントの見え方が変わることがあります
- 標準の日本語フォントが利用できる環境での使用を推奨します

## Python環境(py)

### 実行時にモジュールエラーが出る

- `requirements.txt` を使って依存パッケージを入れ直してください
- 仮想環境を使っている場合は、実行時と同じ環境が有効になっているか確認してください

### 出力が遅い

- 大きな Excel ファイルでは読み込みに時間がかかることがあります
- `fastexcel` が入っていない場合は、`openpyxl` にフォールバックします

### 入力ファイルの読み込みに失敗する

- ファイルが別のアプリで開かれていないか確認してください
- パスに日本語や空白が多い場合は、別の場所へ移して試してください
