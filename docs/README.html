機能

⚡ 高速データ読み込み
fastexcel エンジンによる高速化（フォールバック対応）
🧹 自動データクレンジング
全角英数字変換、列名の自動生成・重複排除
📈 複数指標の計算
  • 授業数（出席人数）
  • 宿題平均ページ数
  • ラップテスト実施状況
  • 確認テスト実施状況
  • テスト実施率
📋 週別レポート生成
ピボット処理による講師別・週別の見やすいサマリー
✨ 高度なExcel装飾
  • 条件付き書式（宿題平均 < 6ページ：オレンジ、テスト率 < 70%：赤）
  • ペイン固定・オートフィルター設定
  • 日本語フォント対応（Noto Sans JP）
  • 高DPI対応

必要要件

  • Python 3.8以上
  • 必要なパッケージ:
パッケージ 説明 必須
polars 高速データフレーム処理 ✅
openpyxl Excel読み書き ✅
xlsxwriter 高速Excel出力 ✅
fastexcel 高速Excelリーダー 推奨

インストール

推奨方法

pip install -r requirements.txt

個別インストール

pip install polars openpyxl xlsxwriter fastexcel
⚠️ 注意: fastexcel は一部の環境ではインストールに時間がかかることがあります。インストール失敗時は openpyxl へ自動フォールバックされます。

使用方法

基本的な実行方法

python MSLdata_check.py

GUI ファイルダイアログが表示されるので、集計元の Excelファイル（.xlsx/.xls/.xlsm）を選択してください。

✅ 処理フロー:
  1. ファイル選択ダイアログが表示
  2. Excelファイルを読み込み
  3. データクレンジングと指標計算
  4. 週別集計とピボット処理
  5. Excel出力ファイルを生成
  6. 完了メッセージを表示

入力ファイルの要件

必須列

列名 説明 例
出欠 出席状況 出席、欠席
担当講師名 講師名 田中太郎
担当講師N0 講師ID 001
教室 教室情報 A教室

オプション列

  • 日付 または 授業日 - 集計期間の自動判定用
  • ラップテスト系の列 - ラップテスト実施状況
  • 確認系の列 - 確認テスト実施状況
  • 宿題名系の列（3列1セット）:
    • 宿題名
    • 宿題開始ページ
    • 宿題終了ページ

出力ファイル

生成されるファイルの形式:

集計結果_[YYYYMMDD-YYYYMMDD]_YYMMDD-HHMMSS.xlsx

ファイルは入力ファイルと同じディレクトリに出力されます。

シート構成

列 説明 背景色
No 講師ID （なし）
氏名 講師名 （なし）
教室 教室 （なし）
総授業数 全週の授業数合計 Lavender #E6E6FA
授業1, 授業2,... 各週の出席数 Khaki #F0E68C
平均HW1, 平均HW2,... 各週の宿題平均ページ数 グレー/白 交互
Lap数1, Lap数2,... 各週のラップテスト実施数 グレー/白 交互
Lap％1, Lap％2,... 各週のラップ実施率 グレー/白 交互
テスト数1, テスト数2,... 各週の確認テスト実施数 グレー/白 交互
テスト％1, テスト％2,... 各週のテスト実施率 グレー/白 交互

条件付き書式

  • 宿題平均 < 6ページ: オレンジ背景
  • テスト実施率 < 70%: 深紅背景（白文字）

技術詳細

データ処理フロー

  1. ファイル読み込み
    • fastexcel → openpyxl へのフォールバック対応
    • 余分な列の自動ネーミング
  2. データクレンジング
    • 出席データのフィルリング
    • 全角英数字 → 半角変換
  3. 指標計算
    • 宿題ページ数: 終了ページ - 開始ページ + 1
    • テスト実施有無の判定
  4. ピボット処理
    • 講師・教室別、週別の集計
  5. Excel出力
    • xlsxwriter による高速フォーマット
    • 日本語フォント対応
    • 高DPI対応

パフォーマンス

10,000行程度のデータで数秒以内に完了

トラブルシューティング

❌ エラー「必須の列が見つかりません」

入力ファイルに以下の列が存在することを確認してください:

  • 出欠
  • 担当講師名
  • 担当講師N0
  • 教室

❌ ファイルが開けない

  • Excelファイルが破損していないか確認
  • .xlsx, .xls, .xlsm 形式に対応しています

⏱️ Excel出力が遅い

  • 大規模ファイル（50,000行以上）の場合、読み込みに時間がかかることがあります
  • fastexcel パッケージが正しくインストールされているか確認

🖥️ Windows DPI対応

このツールは高DPI ディスプレイに自動対応します:

  • GUI自動スケーリング
  • フォント自動調整
  • 日本語フォント（Noto Sans JP）使用で見やすさ向上
